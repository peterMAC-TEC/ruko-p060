## Recording on Windows, one step at a time
1. Open the browser full screen (F11).
2. Press **Win + G** to open the Xbox Game Bar. The first time, allow it.
3. Click the **Capture** widget, then the round **Record** button (or press **Win + Alt + R**). To record your voice, turn the microphone icon on.
4. Do the run. Press **Win + Alt + R** again to stop.
5. The video is in **Videos → Captures**.

If Game Bar is not available, install OBS Studio (free), add a "Display Capture" source and press Start Recording.
